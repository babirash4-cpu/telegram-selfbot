# 🤖 سلف بات تلگرامی پیشرفته تک کاربره (Railway Ready)

یک سلف بات مدرن، پرسرعت، فوق سبک و تک کاربره با تمرکز بر امنیت، عملکرد بالا و حذف کامل هرگونه سیستم تبلیغاتی، فروش اشتراک و کدهای اضافی.

---

## ✨ ویژگی‌ها و قابلیت‌های کلیدی

1. **🎰 بخش کامل کازینو و شرط‌بندی:**
   - پرتاب تاس جادویی، دارت، بسکتبال، فوتبال، اسلات ماشین و بولینگ با اموجی‌های اختصاصی تلگرام
   - موتور محاسبه ضرایب و سود/زیان خودکار
   - سیستم مدیریت سرمایه با امکان تعیین سقف شرط‌بندی و حد ضرر خودکار (Stop-Loss)
   - بازی دوز و چالش‌های سرگرم‌کننده

2. **🛡️ سیستم پیشرفته آنتی‌دلیت و ویرایش:**
   - رهگیری آنی تمامی پیام‌های پاک شده در پیوی و گروه‌ها
   - ردیابی تغییرات و متن قبلی/جدید در پیام‌های ادیت شده
   - فوروارد خودکار متن و رسانه‌ها (عکس، ویس، فیلم، آهنگ، داکیومنت) به Saved Messages (پیام‌های ذخیره شده) یا ربات هلپر
   - بافر بهینه‌سازی شده در حافظه بدون اشغال دیسک

3. **⏰ ساعت هوشمند و زیباسازی بیو و نام:**
   - نمایش زمان با فونت‌های یونیکد و فارسی (توپر، حبابی، مونواسپیس، فارسی اصیل)
   - قابلیت درج قلب‌های رنگی متحرک یا نمادهای وضعیت
   - سازگاری با تاریخ شمسی و میلادی
   - حفاظت هوشمند در برابر FloodWait تلگرام با کش داخلی

4. **🤖 منشی هوشمند و حالت غیبت (AFK):**
   - پاسخگویی خودکار در پیوی با دلیل غیبت سفارشی
   - سیستم کول‌داون ضد اسپم (عدم ارسال مکرر به یک کاربر)
   - سیستم پاسخ سریع به کلمات کلیدی دلخواه (Triggers)
   - لیست سفید دوستان و آشنایان

5. **⚔️ سیستم انمی و ضدحال هوشمند (Enemy System):**
   - تعیین افراد خاص برای پاسخ کوبنده خودکار
   - حالت‌های استیکری، ویس و متنی به محض ارسال پیام توسط شخص

6. **🛠️ ابزارهای مدیریتی و کاربردی:**
   - دستور پاکسازی سریع (`.purge [تعداد]`)
   - ذخیره رسانه‌های یکبار مصرف و محدود شده (`.save`)
   - تگ همگانی با رعایت تاخیر ضد بن تلگرام (`.tagall`)
   - استعلام مشخصات کاربران و چت‌ها (`.info`)
   - ماشین حساب ریاضی درون‌برنامه‌ای (`.calc`)
   - تست پینگ و وضعیت آنلاین سلف (`.ping`)

7. **📱 پنل شیشه‌ای تلگرام (Helper Bot):**
   - کنترل پنل اختصاصی با دکمه‌های اینلاین شیشه‌ای
   - دسترسی انحصاری برای مالک (OWNER_ID)
   - امکان فعال/غیرفعال‌سازی سریع قابلیت‌ها با یک کلیک

## 🚀 راهنمای استقرار در Railway.com (ظرف ۲ دقیقه)

1. وارد حساب کاربری خود در [Railway.app](https://railway.app) شوید.
2. روی **New Project** کلیک کرده و گزینه **Deploy from GitHub repo** یا آپلود مستقیم را انتخاب کنید.
3. در بخش **Variables** پروژه، متغیرهای زیر را وارد نمایید:

| نام متغیر | توضیحات | اجباری/اختیاری |
| :--- | :--- | :--- |
| `API_ID` | شناسه API تلگرام از my.telegram.org | **اجباری** |
| `API_HASH` | هش API تلگرام از my.telegram.org | **اجباری** |
| `SESSION_STRING` | سشن استرینگ اکانت شما (با اسکریپت `generate_session.py`) | **اجباری** |
| `OWNER_ID` | آیدی عددی تلگرام شما | **اجباری** |
| `BOT_TOKEN` | توکن ربات تلگرام برای پنل شیشه‌ای از @BotFather | اختیاری (پیشنهادی) |
| `PREFIX` | پیشوند دستورات (پیش‌فرض: `.`) | اختیاری |
| `TZ` | منطقه زمانی (پیش‌فرض: `Asia/Tehran`) | اختیاری |

4. پروژه به صورت خودکار با `railway.json` و `Procfile` شناسایی شده و لانچ می‌شود!

## 💻 اجرای محلی (Local Run)

```bash
# نصب پکیج‌ها
pip install -r requirements.txt

# تنظیم فایل کانفیگ
cp .env.example .env
# ویرایش .env با اطلاعات خود

# اجرای سلف بات
python run.py
```

## 📜 لیست دستورات سلف بات (در هر چت)

- `.help` : نمایش لیست کامل راهنما
- `.ping` : نمایش پینگ و آپ‌تایم سلف
- `.dice [مبلغ]` : تاس جادویی کازینو
- `.dart [مبلغ]` : پرتاب دارت کازینو
- `.slot [مبلغ]` : اسلات ماشین
- `.balance` : مشاهده موجودی و سوابق شرط‌بندی
- `.antidelete` : تغییر وضعیت آنتی‌دلیت
- `.clock` : تغییر وضعیت ساعت روی پروفایل
- `.setclock font [bold|persian|mono|bubble]` : تغییر فونت ساعت
- `.afk [دلیل]` : رفتن به حالت غیبت
- `.unafk` : بازگشت از غیبت
- `.secretary` : روشن/خاموش کردن منشی
- `.enemy [mode]` : اضافه کردن تارگت روی پیام ریپلای شده
- `.delenemy` : حذف تارگت
- `.purge [تعداد]` : حذف سریع پیام‌ها
- `.save` : ذخیره رسانه محدود/تایمردار
